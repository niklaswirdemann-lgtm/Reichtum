# Montageservice – Website

Statische One-Page-Website für einen Montageservice (Möbel, Küchen, Lampen, Gardinen, TV, Demontage).

## Ansehen
`index.html` im Browser öffnen – kein Build nötig.

## Anpassen
- Firmenname, Telefon, E-Mail, Adresse: in `index.html` (Platzhalter `0000 / 000 000`, `info@example.de`, `Musterstraße 1`)
- Farben: `--brand` in `assets/styles.css`
- Preise und Leistungen: Abschnitte `#preise` und `#leistungen` in `index.html`
- Impressum & Datenschutz: `impressum.html`, `datenschutz.html` (Pflicht in Deutschland)
- Kontaktformular öffnet aktuell das E-Mail-Programm; für echten Versand z. B. Formspree einbinden.
